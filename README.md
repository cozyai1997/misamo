# Misamo

미사모 홈페이지 GUI 정적 페이지입니다.

## 수정 위치

- 화면 구조와 문구: `index.html`
- 스타일 목차: `styles.css`
- 색상, 그림자, 공통 테마 값: `css/tokens.css`
- 기본 폰트와 리셋: `css/base.css`
- 로컬 SVG 아이콘 연결: `css/icons.css`
- 상단바, 전체 그리드, 모바일 메뉴 표시: `css/layout.css`
- 버튼, 칩, 액션 컨트롤: `css/buttons.css`
- 왼쪽 사이드바: `css/sidebar.css`
- 중앙 스토리, 히어로, 피드, 게시글: `css/content.css`
- 오른쪽 보조 영역: `css/right-rail.css`
- 반응형 규칙: `css/responsive.css`
- 이미지 파일: `img/`
- 아이콘 파일: `icon/`
- 추후 JavaScript 기능: `js/main.js`

각 CSS 파일 첫 줄의 `EDIT:` 주석을 보면 수정 범위를 빠르게 확인할 수 있습니다.

## 연결된 화면 동작

- 배너 이전/다음 버튼, 점 버튼, 5초 자동 넘김: `js/main.js`
- 피드 탭 필터와 검색 필터: `js/main.js`
- 최신순/인기순 정렬 토글: `js/main.js`
- 좋아요, 공유, 저장 버튼 상태 변경: `js/main.js`
- 탐색 메뉴 클릭 시 전용 탐색 페이지 열기: `js/main.js`
- 사이드바/모바일 메뉴 active 상태 변경: `js/main.js`
