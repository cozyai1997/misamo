# Misamo

미래 사장님들의 모임 **misamo** 정적 사이트와 브라우저 저장형 포스팅 시안입니다.

## 구성

- 정적 홈페이지: `index.html`
- 스타일: `styles.css`
- 화면 전환·배너·좋아요: `script.js`
- 포스팅 작성·미리보기·이미지 첨부: `posting.js`, `posting.css`
- 본문 이미지 위치 저장·안전한 표시: `post-content.js`
- 사진 드래그 이동·크기 조절·문단/사진 정렬: `editor-media.js`
- 브라우저 임시저장·발행 글·댓글 저장: `post-store.js`
- 게시글별 댓글·답글·수정: `comments.js`, `comments.css`

## 임시 버전 사용

링크 카드는 본문 너비에 맞춰 최대 480px의 자동 크기로 표시되며 수동 크기 조절은 하지 않습니다. 기존에 저장한 카드 너비도 자동 크기로 복원됩니다. 글 사이 드래그 이동, 왼쪽·가운데·오른쪽 정렬, Delete 삭제 및 실행 취소는 유지됩니다. 오른쪽 클릭의 `링크 수정`에서 주소를 바꾸면 미리보기를 다시 가져오며, 실패 시 기존 카드를 유지합니다. 링크 추가·수정·빈 문단 붙여넣기에 `naver.com`처럼 주소만 입력해도 `https://`를 자동으로 붙입니다. 명시적인 HTTP 주소도 HTTPS로 연결합니다. 일반 사진의 수동 크기 조절은 유지합니다.

링크 카드는 최대 480px 너비의 작은 형태로 표시됩니다. 글쓰기 중에는 카드를 눌러도 이동하지 않으며, 카드에서 오른쪽 클릭 후 `링크 보기`를 눌러 새 탭으로 열 수 있습니다. 메뉴는 바깥 클릭이나 Esc로 닫습니다. 미리보기와 게시된 글에서는 기존처럼 카드를 클릭하면 링크가 열립니다.

빈 문단에 HTTPS 주소 하나를 붙여넣으면 대표 이미지·제목·설명·도메인을 표시하는 링크 카드로 추가됩니다. 도구 모음의 링크 버튼도 빈 문단에서는 같은 방식입니다. 문장 속 붙여넣기는 일반 텍스트로 유지하고, 정보를 가져오지 못하는 사이트는 주소로 남깁니다. 카드 정보는 임시저장·미리보기·브라우저 내 게시·실행 취소에 포함됩니다.

링크 미리보기는 `api/link-preview.js`의 Vercel Node 함수가 공개 HTTPS 페이지의 메타데이터만 조회합니다. 비공개 IP·내부 주소·임의 포트·인증정보 포함 URL은 차단하고 DNS 확인 결과에 연결을 고정합니다. 리다이렉트마다 다시 검증하며 조회는 5초·HTML 512KB·리다이렉트 3회로 제한합니다. 썸네일은 원본 사이트에서 직접 불러오며 사이트의 차단 정책에 따라 표시되지 않을 수 있습니다. 별도 API 키나 DB는 필요하지 않습니다. 로컬 API/화면 확인은 `node tests/preview-dev-server.cjs`로 실행합니다.

상단 `새 글` 버튼에서 작성 화면을 엽니다. 글 작성, 임시저장, 미리보기, 브라우저 내 발행과 댓글을 시험할 수 있습니다.

사진 파일을 본문에 끌어 놓거나, 원하는 위치를 클릭한 뒤 도구 모음의 `이미지 넣기`를 누르세요. 본문의 사진을 드래그하면 위치 안내선을 따라 이동합니다. 사진을 클릭하면 모서리 손잡이로 비율을 유지하며 크기를 바꾸거나 Delete 키로 삭제할 수 있습니다. 도구 모음의 왼쪽·가운데·오른쪽 정렬은 선택한 사진 또는 현재 문단에 적용됩니다. 별도 하단 첨부 영역과 사진 삭제 버튼은 없으며 이미지 모서리는 직각을 유지합니다.

본문의 글·서식·사진 삽입·이동·크기·정렬·삭제는 Ctrl+Z 또는 실행 취소 버튼으로 되돌립니다. Ctrl+Y, Ctrl+Shift+Z 또는 다시 실행 버튼으로 복구합니다. 사진 이동과 크기 조절은 한 번의 제스처를 한 단계로 기록합니다. 취소 후 새 편집을 하면 다시 실행 기록은 정리됩니다. 최근 최대 60개 상태를 현재 작성 세션에서 유지하며 새로고침이나 게시 후에는 작업 기록이 초기화됩니다. 저장된 본문과 사진은 그대로 복원됩니다.

글 한 문장 사이에도 사진을 넣고 옮길 수 있으며 앞글·사진·뒷글 순서가 유지됩니다. 이동 중에는 사진이 반투명해지고, 글자 사이에는 세로 삽입 커서가, 문단 사이에는 가로 안내선이 표시됩니다. 선택 테두리와 손잡이는 은은하게 표시하며, 가로×세로 크기는 크기 조절 중에만 나타납니다.

사진은 최대 3장·합계 약 1MB로 자동 압축됩니다. 위치·크기·정렬은 임시저장, 미리보기, 게시 후에도 유지됩니다. 이전 임시저장의 별도 첨부 사진은 본문 끝에 복원하고 기존 게시글은 그대로 표시합니다.

- 현재 사용자는 `misamo_korea`로 고정된 시연용 사용자입니다. 실제 로그인이 아닙니다.
- 작성 글과 초안은 현재 사이트 주소의 브라우저 저장소 `misamo.prototype.v1`에 저장되고, 첨부 영상 원본은 IndexedDB `misamo.media.v1`에 저장됩니다. 다른 기기·브라우저·회원에게 공유되지 않습니다.
- 브라우저 데이터를 삭제하면 작성한 내용도 사라집니다. 개인·민감 정보 저장용으로 사용하지 마세요.
- 실제 회원 로그인, 서버 DB, 공개 범위 제어, 메일 발송은 미연결입니다. 준비한 Supabase 프로젝트의 인증 설정은 변경하지 않습니다.
- 홈의 기존 예시 게시글은 시안 자료입니다. 다른 메뉴 일부는 디자인 전용입니다.

## 검증

모바일 본문은 브라우저의 기본 길게 누르기·선택 핸들·복사 메뉴를 사용합니다. 선택 범위에 붙여넣으면 일반 텍스트와 줄바꿈만 입력되며 실행 취소로 복구할 수 있습니다. 메뉴 모양은 OS·브라우저에 따라 다르며 실제 iOS/Android 선택 핸들은 실기기에서 별도 확인해야 합니다.

개발용 의존성을 `npm ci`로 설치한 뒤 `npm test`로 저장·본문 이미지·화면 연동을 검증합니다. jsdom은 테스트 전용이며 운영 사이트에는 포함하지 않습니다. 기존 화면 구성 검사는 `tests/*.ps1`을 실행합니다.
발행·복원·사진 첨부·댓글·수정은 실제 브라우저에서 별도 확인합니다.

## 북마크

홈 게시글과 탐색 추천 카드의 북마크 버튼으로 저장·해제할 수 있으며, 새로 작성한 글에도 같은 버튼이 표시됩니다. 왼쪽 `저장` 메뉴에서 목록을 확인하고 제목을 누르면 원래 게시글로 이동합니다.

기존 `misamo.prototype.v1` localStorage 데이터에 `bookmarks` ID 배열을 추가하며 작성 중인 글, 게시글, 댓글, 좋아요는 유지합니다. 같은 브라우저·사이트 주소에서 새로고침 후에도 유지되고, 다른 탭의 변경도 반영합니다. 계정·기기 간 동기화는 제공하지 않습니다. 저장이 차단되면 오류를 표시하고 성공 상태로 바꾸지 않습니다.

저장 화면은 썸네일 카드와 목록 보기, 콘텐츠 분류 및 저장순/제목순 정렬을 제공합니다. `새 폴더 만들기`로 폴더를 만든 뒤 각 카드 아래에서 폴더를 지정할 수 있습니다. 폴더와 배정 정보도 기존 저장소에 함께 보관합니다. 오른쪽 폴더·태그를 누르면 해당 콘텐츠만 표시되며, 개수는 실제 북마크 기준입니다. 모바일 하단의 저장 바로가기는 제거했으며 저장 기능 자체는 유지합니다.

## 홈 본문 읽기와 인라인 댓글

긴 글은 완성된 문장·문단 단위의 미리보기와 `본문 펼치기`를 제공합니다. 펼친 원문은 한 열로 표시하며 이미지·링크·서식 순서를 유지합니다. 본문 아래 `본문 접기`는 해당 게시글 위치로 돌아갑니다. 짧은 글은 그대로 표시하고, 여러 줄 목록도 길이 판정에 포함합니다. 이미지에는 전체 보기 기능이 있으며 표가 있는 원문은 표 영역만 가로 이동할 수 있습니다.

제목을 누르면 `#post/게시글ID` 전용 읽기 화면이 열리고 `홈으로 돌아가기`로 원래 위치와 키보드 초점을 복원합니다. 직접 작성한 글은 기존과 같이 현재 브라우저 localStorage에 저장되므로 다른 기기에서 해당 주소만 열어 글을 불러올 수는 없습니다. 존재하지 않는 글에는 안내를 표시합니다.

댓글은 평소 접혀 있으며 댓글 아이콘을 누르면 색이 바뀌고 게시글 아래에 입력창과 최신 댓글 2개를 표시합니다. 댓글과 답글은 10개씩 더 볼 수 있으며 답글의 표시 들여쓰기는 한 단계입니다. 댓글·답글·본인 댓글 수정·좋아요를 유지하고, 접기·펼치기·정렬 중에도 작성 중인 입력을 유지합니다. 저장에 실패하면 입력을 지우지 않으며 읽을 수 없는 기존 데이터는 덮어쓰지 않습니다. 댓글 수는 실제 접근 가능한 데이터 기준으로 표시합니다.


## SNS 동작 시제품 (2026-09-14)

홈 필터·정렬, 팔로잉 피드, 작성자 프로필·수정, 글/사람/자료 검색과 접힌 조건 필터를 연결했습니다. 게시글 더보기는 내 글 수정·삭제와 타인 글 팔로우·즐겨찾기·숨김·30일 숨김·차단·신고·알림 구독을 구분합니다. 숨김·차단 및 삭제한 내 글은 프로필 메뉴의 관심·숨김 관리에서 복원합니다. 고유 글·프로필 주소로 다시 들어올 수 있으며 삭제된 글은 읽기 화면에서도 열리지 않습니다.

사진은 첨부 순서에 따라 이전/다음/위치 표시를 제공하고, 전체 보기에서는 선택한 사진을 유지하며 방향키로 이동합니다. 기존 긴 본문과 댓글 입력을 보존합니다. 공유는 링크 복사/기기 공유와 로컬 메시지를 구분합니다. 링크 HTML은 링크용 마크업입니다.

`community-data.js`는 별도 `misamo.community.v1` localStorage에 개인 활동과 글 수정본을 저장합니다. 기존 게시글·초안·댓글 저장소를 초기화하지 않습니다. 동기화되는 회원 서비스가 아니므로 브라우저·프로필·주소(포트)가 다르면 개인 상태가 다릅니다. localhost의 10개 공통 테스트 글은 `local-test-posts.js`에서 제공됩니다.

메시지·신고·알림 구독·상담/세미나 신청은 실제 수신자나 운영자에게 전송되지 않는 로컬 기록입니다. 활동에는 이 브라우저의 기록만 표시합니다. 교육/상담 목록과 다운로드 가능한 CSV 양식은 개발용 예시입니다. Auth/DB, 실제 메시지 전달, 운영자 신고 처리, 실시간 수신 알림, 리포스트 및 만료형 스토리는 이번 단계에 포함하지 않습니다.


## 영상 첨부 (2026-09-21)

글쓰기의 `영상 넣기`로 MP4, WebM 또는 MOV 파일을 1개, 최대 100MB까지 첨부합니다. 영상의 크기·길이를 확인하고 원본 저장이 완료된 뒤에 첨부 상태를 반영합니다. 모바일 절약 모드에서 첫 프레임의 자동 로딩을 기다리지 않으며, 파일 선택기가 형식 정보를 생략한 경우에는 지원 확장자로 형식을 보완한 뒤 실제 영상 정보를 검사합니다. 저장 공간 부족이나 검사 오류가 발생하면 기존 영상과 작성 내용을 유지합니다. 코덱 지원 여부는 기기·브라우저에 따라 다르며 재생 단계의 오류는 플레이어에 표시합니다. 원본 변환·인코딩은 하지 않습니다.

첨부 영역에서 **4:3 가로 / 1:1 정사각 / 9:16 세로 / 16:9 가로**를 선택하며 미리보기·게시글·수정·새로고침에 같은 설정을 적용합니다. 선택한 비율의 프레임을 채우도록 중앙 기준으로 크롭해 표시합니다. 원본보다 프레임이 넓으면 위아래, 좁으면 좌우가 잘리며 검은 여백을 추가하지 않습니다. 비율을 바꾸면 즉시 보이는 범위를 확인할 수 있습니다. 원본 파일은 보존하며 별도로 인코딩하지 않습니다. 영상은 접히는 긴 본문 밖의 별도 영역에 표시되며 재생·탐색·음량·전체화면은 브라우저 기본 플레이어로 조절합니다. 자동 재생하지 않습니다.

`video-media.js`가 파일 검증·IndexedDB 저장·재생 URL의 수명 관리를 담당합니다. 게시글에는 파일 ID와 표시 설정만 저장하며, `blob:` URL이나 영상 Base64는 저장하지 않습니다. 브라우저 저장소를 지우면 직접 첨부한 영상도 사라집니다. 글에서 영상을 빼거나 교체해도 복원 가능한 게시글·초안에서 사용할 수 있도록 저장된 원본은 즉시 삭제하지 않습니다. 공개 업로드 서버·다른 기기 간 동기화·영상 인코딩은 현재 단계에 포함되지 않습니다.

`local-test-video.js`의 예시 글 **짧은 영상으로 시선을 끄는 법 — 숏폼 레퍼런스**는 localhost에서만 제공합니다. 제공받은 720×1280, 약 19.75초 MP4를 `assets/local-test-media/yena-catchcatch.mp4`에 복사했으며 원본 다운로드 파일은 유지합니다. 동일한 로컬 서버를 여는 다른 브라우저에서도 예시 글이 나타납니다. 예시 영상 파일은 Git/Vercel 업로드 대상에서 제외했습니다. 게시글 주소: `http://127.0.0.1:8765/#post/local-video-catchcatch-20260921`.

참고한 공식 안내: [Threads 재생 컨트롤](https://about.fb.com/news/2025/03/new-threads-features-more-personalized-experience-you-control/), [Facebook 영상 탐색·전체화면](https://about.fb.com/news/2024/04/exploring-videos-on-facebook-just-got-easier/), [Instagram·Facebook Reels 광고](https://www.facebook.com/business/ads/facebook-instagram-reels-ads). ### 사진·영상 함께 보기

사진(최대 3장)과 영상(1개)을 함께 첨부하면 게시글 아래 하나의 캐러셀로 표시합니다. 작성 화면에서 공통 비율(4:3, 1:1, 9:16, 16:9)과 순서를 지정하며, 첫 첨부파일이 대표 화면입니다. 사진은 첨부 영역의 `빼기`로 제거할 수 있습니다. 기존 사진만 있는 본문 편집은 유지됩니다.

- 사진/영상은 선택한 비율로 중앙 크롭하며 원본 파일은 유지합니다. 사진 클릭 시 원본 전체 보기를 지원합니다. 영상 전체화면에서는 원본 비율을 유지하는 contain 표시로 전환하고 남는 공간은 검게 표시합니다.
- 사진과 영상을 가로 카드 줄로 표시하고 다음 카드 일부를 노출합니다. 화살표, 사진을 마우스로 끌기, 키보드 좌우 이동, 모바일 기본 가로 스크롤을 지원합니다. 영상은 자동 재생하지 않고 다른 첨부파일로 이동하면 정지합니다.
- `mediaOrder`, `mediaRatio`, `mediaLayout`을 기존 게시글/초안 저장소에 함께 저장합니다. 영상 데이터는 기존 IndexedDB를 사용합니다.
- 로컬 공통 예시: `http://127.0.0.1:8765/#post/local-mixed-media-20260921`. 기존 제공 영상과 프로젝트 이미지 2장을 활용하며, 공개 호스트에서는 예시를 추가하지 않습니다.


## 게시글 작성 형식 (2026-09-21)

새 글 작성의 **게시글 형식**에서 두 가지를 선택합니다.

- **아래에 모아보기**: 본문 아래에서 사진·영상을 좌우로 넘겨봅니다. 첫 첨부파일이 대표 화면입니다.
- **본문에 넣기**: 커서 위치에 사진·영상을 넣고 이어서 작성합니다. 사진·영상의 크기·정렬·드래그 기능을 제공하며, 각 미디어 왼쪽 위 **대표** 버튼으로 홈 미리보기의 첫 항목을 고릅니다. 본문 미디어는 각자 비율을 유지하고 홈의 미디어 미리보기만 대표 항목의 비율을 따릅니다. 홈 요약 아래에는 사진·영상을 가로로 표시하며, 본문을 펼치면 미리보기를 숨기고 본문 순서대로 전체를 표시합니다.

형식 변경은 첨부파일을 삭제하지 않으며 원래 본문 위치를 유지합니다. 모아보기 상태에서 본문을 모두 다시 작성해 위치 표식이 사라진 경우, 본문형 전환 시 기존 첨부는 끝에 복원됩니다. 본문에서 직접 삭제한 미디어는 형식을 바꿔도 되살아나지 않습니다. 형식, 대표사진, 영상 교체·이동·삭제는 실행 취소/재실행으로 복구할 수 있습니다.

저장은 기존 localStorage/IndexedDB 구조를 사용합니다. mediaLayout은 carousel/inline 또는 기존 자료의 빈 값이며, 본문 영상은 검증된 data-video-id만 저장합니다. 실제 영상은 기존 동영상 모듈로 연결하므로 본문 HTML에 Blob 주소나 원본 파일을 저장하지 않습니다. 기존 게시글은 읽을 때 원래 형식을 유지하고, 수정 화면은 기존 사진형/영상형 배치를 구분해 복원합니다.

참고 조사: 당근비즈니스 공식 교육 [인기 소식의 비밀](https://business.daangn.com/edu/vod/f9ee6722-b40a-40dd-a56f-3a3848b1b255/)에 소식 에디터(00:33), 에디터 변경 방법(01:21)이 안내되어 있습니다. 현재 로그인 계정의 옵션 명칭과 상세 지원 범위는 직접 검증하지 않았으며, 위 두 형식과 동작은 미사모 요구사항에 맞춘 구현입니다.


### 첨부 화면 위 편집 도구

- 본문 영상의 비율은 영상 오른쪽 위에서 선택합니다(4:3, 1:1, 9:16, 16:9). 옆 삭제 버튼과 실행 취소를 지원하며, 이전의 하단 영상 옵션창은 제거했습니다.
- 모아보기의 첨부 순서는 각 카드 오른쪽 위 숫자로 표시됩니다. 숫자를 눌러 위치를 고르거나 카드를 좌우로 드래그해 변경할 수 있습니다. 별도 점 모양 이동 손잡이는 제거했습니다. 터치·키보드에서는 숫자 선택으로 같은 작업을 수행합니다. 처음에는 업로드 순서로 추가되며 이후 지정 순서를 저장합니다. 모아보기에서는 첫 카드의 비율을 선택하고 나머지 카드는 자동으로 맞춥니다.
- 본문형 사진·영상은 오른쪽 위에서 비율을 선택합니다. 대표 버튼과 비율 선택은 마우스 접근·키보드 초점에 따라 표시되며 터치 환경에서는 접근 가능한 상태를 유지합니다. 활성화된 대표 버튼은 계속 표시됩니다.
