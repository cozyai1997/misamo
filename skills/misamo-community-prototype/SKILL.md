# 커뮤니티 화면과 사용자 행동

미사모에서 추출한 구현 지침이다. 다른 사이트에서도 사용할 수 있으며 대상의 기술 스택·데이터 계층·브랜드·사용자 요구를 우선한다.

## 구현 순서

1. 홈·팔로잉·탐색·프로필의 목적과 공통 게시글 모델을 정하고 동일한 ID로 연결한다. 검색은 글/사람/자료 결과를 구분하고 고급 조건은 필요할 때 펼친다.

2. 더보기 메뉴는 내 글 수정/삭제와 타인 글 팔로우/숨김/차단/신고를 구분한다. 숨김·차단·삭제 규칙을 목록과 상세 조회에 함께 적용한다.

3. 공유 링크 복사·기기 공유·내부 메시지 전달을 별도 동작으로 다룬다. 실제 전송 서버가 없으면 로컬 기록임을 UI와 완료 보고에 명시한다.

4. 네트워크 서비스에서는 로그인 사용자, 서버 권한, 차단 범위, 신고 처리와 수신 상태를 서버 모델로 설계한다. 미사모의 고정 사용자와 localStorage를 인증·운영 시스템으로 재사용하지 않는다.

5. 기존 화면의 placeholder를 발견했다고 작업 범위를 임의로 늘리지 않는다. 요청한 동작의 저장·복구·빈 상태·오류 경로까지 연결한다.

## 검증

내 글/타인 글 메뉴, 숨긴 글의 상세 진입, 팔로잉 빈 피드, 검색 조합, URL 직접 진입, 로컬 메시지와 실제 전송의 표시 차이를 확인한다.

## 구현 참고

실제 코드 구조나 회귀 테스트가 필요할 때 [미사모 참조](references/misamo.md)를 읽는다. 스킬 단독으로 사용할 때 참조 저장소 전체를 복제할 필요는 없다.
