# 긴 게시글 읽기

미사모에서 추출한 구현 지침이다. 다른 사이트에서도 사용할 수 있으며 대상의 기술 스택·데이터 계층·브랜드·사용자 요구를 우선한다.

## 구현 순서

1. 요약과 원문을 별도 렌더링하되 원문을 유일한 콘텐츠 기준으로 둔다. 요약을 저장 원문에 덮어쓰거나 CSS 잘림만으로 본문을 제공하지 않는다.

2. 문장·문단과 목록을 고려해 요약하고 펼치기 버튼을 제공한다. 펼친 원문은 글·사진·영상·링크 순서를 유지하며 표처럼 넓은 요소만 내부 가로 스크롤을 허용한다.

3. 본문형 글의 미디어 미리보기를 아래 캐러셀로 보여주는 경우 펼칠 때 중복 미리보기를 숨기고 재생 중인 영상을 정지한다. 전체 원문에는 삽입 위치대로 표시한다.

4. 본문 아래에서 접으면 해당 카드 위치로 이동한다. 고유 게시글 화면은 주소 직접 진입·뒤로 가기를 지원하고 원래 피드의 스크롤과 초점을 복원한다.

5. 삭제·숨김·없는 ID는 안내 상태로 처리한다. 브라우저 로컬 글의 URL을 다른 기기에서도 조회 가능한 공개 링크라고 설명하지 않는다.

## 검증

매우 긴 한 문단, 긴 목록, 짧은 글, 다수 미디어, 표, 펼친 글 아래서 접기, 상세화면 뒤로 가기, 직접 진입한 없는 ID를 확인한다.

## 구현 참고
