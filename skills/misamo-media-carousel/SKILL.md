# 사진·영상 모아보기

미사모에서 추출한 구현 지침이다. 다른 사이트에서도 사용할 수 있으며 대상의 기술 스택·데이터 계층·브랜드·사용자 요구를 우선한다.

## 구현 순서

1. 미디어마다 image ID 또는 video:ID처럼 충돌 없는 key를 두고 순서는 별도 배열로 보관한다. 재정렬은 배열 위치만 바꾸며 원본·문서 위치를 변경하지 않는다.

2. 업로드 순서, 현재 표시 순서, 대표 항목을 구분한다. 첫 항목을 대표로 삼을지 별도 coverId를 쓸지는 제품 요구에 맞춘다. 삭제·교체 후 유효한 key만 남도록 정리한다.

3. 가로 스크롤 줄에 다음 항목 일부를 보여줄 수 있다. 좌우 버튼과 키보드 이동을 제공하고, 드래그를 사용할 수 없는 터치/키보드에는 숫자 순서 선택 등 대체 조작을 둔다.

4. 그룹 미리보기 비율과 각 파일 원본 비율을 분리한다. inline 형식의 미디어를 미리보기로 모아 보여도 원문 비율을 동기화하지 않는다. 사진 전체 보기와 영상 전체화면은 원본 비율을 유지한다.

5. 포인터 장치의 숨김 화살표는 hover와 focus-within에서 표시한다. 터치에서 hover를 요구하지 않는다. 영상 컨트롤 드래그와 캐러셀 드래그가 경쟁하지 않게 한다. 항목을 벗어난 영상은 정지한다.

## 검증

사진/영상 혼합, 번호 변경과 드래그, 첫/마지막 항목, 대표 삭제, 영상 교체, 손가락 가로 스크롤, 키보드, 가로·세로 화면, 저장 후 순서 복원을 확인한다.
