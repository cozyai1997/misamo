# 본문 해시태그 자동 등록

미사모에서 추출한 구현 지침이다. 다른 사이트에서도 사용할 수 있으며 대상의 기술 스택·데이터 계층·브랜드·사용자 요구를 우선한다.

## 구현 순서

1. 본문은 원본이고 태그 칩은 검색/분류용 별도 메타데이터로 다룬다. 칩 삭제가 본문 #문구를 수정하지 않게 한다.

2. 수동 태그, 본문에서 추출한 태그, 사용자가 자동 등록을 제외한 태그를 구분한다. 제외 집합을 초안에 저장해 다음 입력/새로고침에 삭제한 칩이 다시 살아나지 않게 한다.

3. 문자 허용 범위·유니코드 정규화·중복·최대 개수·최대 길이를 제품 정책으로 정한다. 모든 HTML textContent를 그대로 훑으면 미디어 도구·링크 카드의 UI 문자열이 태그가 될 수 있으므로 실제 본문 텍스트만 추출한다.

4. 입력과 IME 완료 시점에 동기화하고 미완성 조합을 여러 태그로 저장하지 않는다. 본문에서 사라진 자동 태그를 정리하되 수동 태그는 유지한다.

5. 수동으로 다시 추가한 태그의 제외 상태를 어떻게 해제할지 정의한다. 제한 초과 시 기존 수동 선택을 임의로 밀어내지 말고 일관된 우선순위와 안내를 적용한다.

## 검증

한글·영문·숫자, 중복, 문장부호, 태그 개수 상한, 칩 삭제 뒤 계속 입력, 새로고침, 수동 재추가, 본문 태그 삭제, IME와 undo를 확인한다.

## 구현 참고
