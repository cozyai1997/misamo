# 본문 사이 사진·영상 편집

미사모에서 추출한 구현 지침이다. 다른 사이트에서도 사용할 수 있으며 대상의 기술 스택·데이터 계층·브랜드·사용자 요구를 우선한다.

## 구현 순서

1. 미디어는 안정적인 ID로 참조하고 문서에는 위치·정렬·표시 크기를 저장한다. 본문 안의 Blob URL을 영구 데이터로 저장하지 않는다. 원본과 렌더링용 DOM을 분리한다.

2. 사진과 영상을 같은 편집 개념으로 다루되 네이티브 영상 재생 컨트롤에서 시작한 조작은 드래그로 가로채지 않는다. 글자 사이·문단 사이의 드롭 위치를 눈에 보이게 표시한다.

3. 본문 미디어의 개별 비율과 홈 미리보기 비율을 분리한다. 대표 항목 변경은 미리보기의 기준만 바꾸며 다른 본문 이미지·영상의 비율을 덮어쓰지 않는다. 정렬 변경 시 원본 비율과 저장된 위치를 유지한다.

4. 대표 버튼, 비율 선택, 삭제 UI를 본문 텍스트 직렬화에서 제외한다. 미사모의 대표 버튼은 왼쪽 위, 비율은 오른쪽 위이지만 다른 사이트의 기존 배치 규칙을 우선한다.

5. 첨부 삭제 시 문서 참조·대표 선택·미디어 순서를 함께 정리한다. 화면 형식 전환만으로 첨부를 삭제하거나 이미 삭제된 미디어를 되살리지 않는다. 기존 저장 자료를 파괴하지 않는 읽기 호환 경로를 둔다.

## 검증

문장 중간 삽입, 문단 사이 이동, 사진/영상 좌·중·우 정렬, 대표 변경, 각자 다른 비율, 삭제 후 undo, 형식 왕복, 저장·복원 후 원래 위치를 검증한다.

## 구현 참고

실제 코드 구조나 회귀 테스트가 필요할 때 [미사모 참조](references/misamo.md)를 읽는다. 스킬 단독으로 사용할 때 참조 저장소 전체를 복제할 필요는 없다.
