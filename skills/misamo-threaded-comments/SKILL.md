# 댓글과 답글

미사모에서 추출한 구현 지침이다. 다른 사이트에서도 사용할 수 있으며 대상의 기술 스택·데이터 계층·브랜드·사용자 요구를 우선한다.

## 구현 순서

1. 댓글은 ID와 parent/root 관계로 저장하고 렌더링 상태와 분리한다. 깊은 답글은 데이터 관계를 유지하면서 화면 들여쓰기 깊이를 제한할 수 있다.

2. 댓글 아이콘의 aria-expanded·색과 실제 열림 상태를 일치시킨다. 기본 접힘 여부와 처음 보여줄 수량은 제품 정책으로 정한다. 댓글 수는 접근 가능한 실제 데이터와 일치시킨다.

3. 더 보기와 정렬은 기존 입력 요소를 불필요하게 갈아 끼우지 않도록 구현한다. 작성 중인 답글·수정값·커서·초점을 보존하고 새 데이터만 추가한다.

4. 최신순/인기순에 동일값 tie-break를 두어 목록이 불안정하게 흔들리지 않게 한다. 저장 실패에는 입력을 남기고 성공한 뒤에만 폼을 비운다.

5. 내 댓글의 수정/삭제 UI를 구분한다. 서버 서비스에서는 권한을 서버에서 검증한다. 브라우저 고정 사용자의 시연용 소유권 검사만으로 실제 회원 보안을 구현했다고 하지 않는다.

## 검증

열기/닫기, 답글 더 보기, 정렬 중 입력 유지, 수정 취소, 저장 실패, 중첩 답글, 폼 초점, 좋아요와 개수 일치를 확인한다.
